# Somatorio-com-fatorial
Este projeto consiste em um programa desenvolvido em *C++* para calcular o valor da soma da série matemática descrita abaixo, permitindo que o usuário defina o limite superior ($n$).

---

## 📐 Fórmula Matemática

O objetivo é calcular a seguinte somatória:

![Somatório](<img width="258" height="228" alt="somatorio com fat" src="https://github.com/user-attachments/assets/23cbe77f-0e01-4e25-b935-23d65df9ad06" />
)

$$\sum_{i=1}^{n} i \cdot i! = 1 \cdot 1! + 2 \cdot 2! + 3 \cdot 3! + \dots + n \cdot n!$$

---

- *Linguagem:* C++
- *Compilador recomendado:* g++ (GCC) / Clang / MSVC
